# Diagnostyka Plus — CFO & PE Quality Review

🔗 **Live dashboard (CFO tool):**  
https://mbimarban.github.io/diagnostyka-plus-cfo/

---

## 🔍 Co to jest?

Interaktywny dashboard analityczny dla Diagnostyka S.A., łączący:

- analizę CFO (cash flow, płynność, marże)
- podejście Private Equity (jakość biznesu, ryzyka, durability)
- storytelling inwestycyjny oparty na danych

Raport został zaprojektowany jako **narzędzie decyzyjne**, a nie statyczny dokument.

---

## 📊 Struktura projektu

- `index.html` — interaktywny dashboard CFO (live)
- `diagnostyka_cfo_storytelling.json` — dane + logika analizy
- `Diagnostyka_CFO_PE.xlsx` — model finansowy

---

## 🎯 Główna teza

Diagnostyka to **silny biznes gotówkowy z trwałą przewagą konkurencyjną**.

Kluczowe pytanie CFO nie brzmi:
> „czy spółka rośnie?”

tylko:
> **„czy ten wzrost utrzymuje jakość gotówki i marż?”**

---

## 🧠 Kluczowy insight

Na każdą **1 zł zysku netto** spółka generuje:

👉 **2,11 zł gotówki operacyjnej (CCR > 2)**

To wskazuje na:
- wysoką jakość zysku
- silny model operacyjny
- brak „papierowego wzrostu”

---

## ⚙️ Jak korzystać

Dashboard został zaprojektowany w stylu CFO:

1. **Snapshot** → szybkie zrozumienie biznesu  
2. **Cash Flow** → czy zysk to gotówka  
3. **Liquidity** → czy spółka jest bezpieczna  
4. **Profitability** → czy marże się zmieniają  
5. **Debt** → czy zadłużenie jest kontrolowane  
6. **Risks** → co może się zepsuć  
7. **Verdict** → końcowy wniosek  

---

## 🚨 Co monitorować (CFO view)

- spadek marż operacyjnych  
- wzrost kosztów usług obcych  
- pogorszenie cyklu gotówki (DSO / CCC)  
- spadek CCR poniżej 1  

---

## 📌 Break points (co psuje tezę inwestycyjną)

- DSO > 55 dni  
- CCR < 1  
- usługi obce > 18% przychodów  
- CFO przestaje rosnąć szybciej niż przychody  

---

## 🏁 Wniosek

Diagnostyka pozostaje:

👉 **wysokiej jakości biznesem gotówkowym**

Główne ryzyko:

👉 **efektywność kosztowa, nie płynność**
